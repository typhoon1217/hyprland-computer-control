# Verified lessons

These initial entries come from the October 12, 2026 display-layout work in Omarchy PR #14533, commit `8259653`. That work used a directly constructed isolated compositor, not the old hypr-ccv launcher. The controller was subsequently rebuilt and tested separately. Do not attribute every observed failure to hypr-ccv itself.

| ID / scope | Observed failure | Prevention and evidence |
|---|---|---|
| L01 — Hyprland 0.56.2 | Launching with only `--socket` failed: both socket and fd are required for handover. Missing `XDG_RUNTIME_DIR` also aborted startup. | Use a real user-owned runtime and auto-generated socket; resolve `hyprctl instances -j` by launched PID. Pass the returned `wl_socket` verbatim; it already includes `wayland-`. |
| L02 — input, Qt 6.11.2 | Blind Tab sequences selected the wrong page/output. Requested `2040` became `12920`; the exact focus/input mechanism was not established. | Observe focus and field content before continuing. Shortcut letters use `wtype -M ctrl -k a -m ctrl`. If that still fails, inspect a new capture and select a visible target rather than repeating the sequence. |
| L03 — render readiness | A screenshot taken immediately after opening a panel showed empty data; one after Keep still showed pending confirmation while backend state was already clear. | Wait for mapped/rendered controls and the expected runtime/UI condition, not only command exit or a fixed short sleep. |
| L04 — output movement | Capturing a moved primary with overlapping outputs produced clipping and a compositor overlap warning. | Recompute geometry and inspect all affected outputs. For a clean secondary-layout demo, position the secondary beside/below the primary. This does not establish that every primary-remapping case is supported. |
| L05 — empty workspaces | Moving an active workspace removed the empty workspace on its destination; a later queued no-op dispatch failed `Workspace not found`. Two empty-workspace swaps have the same disappearance hazard. | Check existence/owner immediately before each dispatch; skip unchanged or vanished empty workspaces. Validate remaining requested owners, persist future empty-workspace rules on Keep. Actual Preview/Revert and empty-swap Preview/Keep passed; stateful fixtures cover disappearance. |
| L06 — full Omarchy shell | An invalid test config fell back to default idle settings. Screensavers later obscured input; writing intended values did not prove effective configuration. | Read back effective shell configuration. Record settings as active only after readback. Inspect layers/clients for idle or lock surfaces before retrying input; terminate only test-owned processes. |
| L07 — profiles and D-Bus | A second full shell sharing the user's D-Bus reported existing notification/polkit agents. | Default to private HOME/XDG roots and a private D-Bus. Expose required external service integration explicitly rather than assuming GUI isolation also isolates services. |

Evidence for L02–L06: `https://github.com/omacom/omarchy/pull/14533`, including `docs/display-layout-validation.json`, inspected screenshots and the 27-second rollback recording. Controller smoke evidence is generated by `tests/smoke.py`; inspect fresh artifacts rather than trusting an older passing run.

## Controller verification — October 12, 2026

- **L08 — clipboard daemon pipes (verified):** `wl-copy` forks a clipboard owner. Inheriting a caller's captured stdout kept `check_output` waiting after the controller exited. Redirect the clipboard helper's stdout/stderr away from caller pipes; keep the owner scoped to the session. The live smoke now completes copy/paste within bounded command timeouts.
- **L09 — mapped vs rendered (verified):** A mapped Qt client was not sufficient to drive its controls immediately; an early click produced no callback. The smoke waits for the app's geometry-ready message to agree with compositor client dimensions before acting, then verifies actual `CLICK=1` and `INPUT=isolated-smoke` callbacks. This is a fixture readiness protocol, not a universal sleep duration.
- **L10 — cleanup/installation review:** Preserve foreign symlinks even when dangling. During shutdown, rescan the exact run marker/runtime within a deadline because termination handlers can launch descendants; retain state if cleanup remains incomplete. Tests exercise a handler spawning a child and stale/reused PIDs.
